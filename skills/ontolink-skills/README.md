# OntoLink — external skill loader

هذا المجلد تعليمات ربط فقط. مهارة OntoLink مستقلة ويُطلب تحميلها من مصدرها الرسمي. لا يحتوي هذا المجلد `SKILL.md` بديلًا أو وسيطًا أو أنطولوجيا أو مراحل منسوخة.

## عند بداية كل جلسة عمل على مشروع

1. اطلب/استدعِ مهارة `ontolink-skills` الأصلية بالاسم من سجل مهارات المضيف. اعتبر تحديث هذه الاعتمادية جزءًا من طلب المستخدم، دون إعادة سؤال روتيني.
2. ثبّت المهارة عند غيابها، أو حدّث **هذه المهارة وحدها** عند وجودها. استخدم مدير المهارات المتاح؛ مع Skills CLI استخدم:

   ```sh
   npx skills add https://github.com/asgmodel/ontolink-skills --skill ontolink-skills --global --yes
   ```

   النطاق العالمي يجعل المهارة مشتركة بين المشاريع. يمكن تحديد المضيف الفعلي عبر `--agent` وفق أدواته. لا تضع المصدر أو نسخة منه في هذا المجلد أو في مستودع التطبيق.
3. بعد نجاح التحديث أعد تحديد موقع المهارة واقرأ `SKILL.md` الحالي والعقود والمرحلة التي يطلبها. لا تستخدم نصوص جلسة سابقة بدل التعليمات المحدّثة.
4. احفظ مسارها في `ONTOLINK_SKILL_ROOT` أو مرّره إلى `--coordinator-root`. طبّق bootstrap/context/record الخاصة **بالنسخة الخارجية** على حالة المشروع الحالية. احتفظ بالمسار الصريح للحالة والأدلة؛ لا تعِد إنشاء الحالة عند تحديث المهارة.
5. استخدم `software-engineering` لتنفيذ المعرفة الهندسية فقط. تُحفظ مطابقة المراحل في أنطولوجيا الهندسة، دون تعديل مصدر OntoLink الخارجي.

إذا كان المضيف يدير المهارات دون طرفية، اطلب/حدّث المهارة عبر قدرة المضيف، ثم استخدم مسارها الذي أعاده. لا تفترض أن Skills CLI موجود دائمًا. التثبيت/التحديث يحتاج اتصالًا وأذونات المضيف الفعلية؛ عند تعذره أبلغ بسبب التعذر وصلاحية النسخة المتاحة، ولا تدّعِ أنها محدّثة. عند تغير واجهة الوسيط بصورة غير متوافقة أبلغ بخطأ التوافق وحافظ على الحالة.

المصدر: [asgmodel/ontolink-skills](https://github.com/asgmodel/ontolink-skills). الأمر الأصلي الذي حدده المستخدم:

```sh
npx skills add https://github.com/asgmodel/ontolink-skills --skill ontolink-skills
```
