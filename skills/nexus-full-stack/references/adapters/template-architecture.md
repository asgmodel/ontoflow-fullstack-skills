# template-architecture: English integration adapter

Resolve and read template-architecture plus architecture.md, source-audit.md and delivery.md. Scaffold only into a new destination using its actual bundled scaffold.py; do not duplicate or reconstruct template assets here. Domain is independent. Application owns DTOs, use cases and ports. Infrastructure implements ports and SQL Server persistence. Controllers stay thin. React belongs in ClientApp, Blazor in Components, built assets in wwwroot. Development Vite is allowed; production uses one ASP.NET process. Preserve project versions, names, existing work and original architectural folders. For an existing non-Template project inspect current architecture and do not force the Template profile. Keep a blank request free of invented features.
